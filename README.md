### 📌 About the Project

A Python-based project that analyzes household electricity consumption using monthly meter readings.

### ✨ Features

- Store household and meter-reading details.
- Calculate monthly electricity consumption.
- Classify usage as Low, Medium, or High.
- Compare household usage.
- Detect unusual consumption.
- Generate monthly reports.
- Suggest energy-saving practices.

### 🛠️ Technologies Used

- Python 3
- SQLite Database
- File Handling
- Exception Handling

### ▶️ How to Run

```bash
py electricity_usage.py
```

### 🧮 Formula

**Electricity Consumption = Current Reading − Previous Reading**

Example: `5140 − 4820 = 320 kWh`

### 🎯 Objective

To analyze electricity usage, identify high consumption, and help households save energy.
